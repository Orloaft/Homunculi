## Flow Summary

```
Source: Sprite Editor UI
    ↓ (user configures)
Generate: hitbox-config.json (temporary)
    ↓ (export process)
Output: scripts/hitbox-config.js
    ↓ (HTML loads)
window.hitboxConfig object
    ↓ (game initialization)
game.js: hitboxConfig.load()
    ↓ (enemy creation)
game.js: createEnemy() calls:
  - applySavedScale()
  - hitboxConfig.applyFlip()
  - applyHitboxConfig()
  - createShadowFor()
```

## How to Update Configuration

1. Open sprite editor: `sprite-editor/enemy-sprite-editor.html`
2. Configure hitboxes, scales, flips, shadows
3. Click "Export" button
4. Generate hitbox-config.json
5. Convert to hitbox-config.js
6. Refresh game page (cache bust with v=8+)
7. Game automatically loads new configuration

## Testing Configuration

To verify configuration is loaded:
1. Open browser console (F12)
2. Check for: `console.log('hitbox-config.js finished loading');`
3. Verify: `typeof hitboxConfig !== 'undefined'`
4. Check: `hitboxConfig.loaded === true`
5. Test: `hitboxConfig.getScale('wizard')` should return 1
