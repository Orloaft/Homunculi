# Comprehensive Element System Balance Guide

## Overview
This document provides complete analysis of all element types, their properties, fusion recipes, acquisition methods, and the tier system used in the game.

## Part 1: All Element Types (35 Total)

### Primary Elements (6 - Obtainable via Level-Up Rewards)
These are the base elements players can choose during level-up rewards.

   - Cooldown: 3150ms (1.2x fire rate)
   - Speed: 380 px/s

## Part 3: Element Acquisition Methods

### Method 1: Level-Up Rewards (Primary Elements Only)
- **When**: Every time player levels up
- **How**: Choose from 3 randomly selected primary elements
- **Primary Elements Pool**: [fire, water, earth, air, lightning, arcane]
- **Available at**: Initial game start + every level up
- **Rarity**: Common (100% guaranteed to get one)

### Method 2: Fusion (All Fusion Elements)
- **When**: During level-up reward selection
- **How**: Choose "Fusion Ritual" option, select 2 elements to combine
- **Result**: Creates new fusion element based on recipe
- **Available fusion results**: 40+ different fusion elements
- **Rarity**: Uncommon (requires deliberate selection)

### Method 3: Level-Up Passive Rewards
- **When**: Along with element/fusion options during level-up
- **How**: Choose passive upgrade instead of element
- **Types**: Revive, Spell Area, Move Speed, Max Health, Damage, Slot Increase
- **Rarity**: Common

### Method 4: Enemy Drops (DISABLED IN CURRENT BUILD)
- **Status**: Commented out - not currently active
- **Note**: Previous system had enemies drop element orbs on death
- **Current Note**: "Elements are now obtained through level ups, not enemy drops"

### Method 5: Chest Rewards
- **When**: Opening treasure chests found in world
- **How**: Open chest and choose from 3 reward options
- **Types**: Can contain elements or passive upgrades
- **Rarity**: Uncommon

### Method 6: Special Drops
- **Mind Orb**: 15% chance on legendary combo OR 10% on epic combo
- **Catalyst**: Special fusion catalyst (1% drop rate on elite kills)
- **Chess Pieces**: Rare special drops from bosses and elite enemies

## Part 4: Element Tier System

### Overview
Each element in each charge slot has an independent tier level (1-5) that scales damage output.

### Tier Scaling (Damage Multiplier)
```
Tier 1: 1.0x (Base damage)
Tier 2: 1.5x
Tier 3: 2.0x
Tier 4: 2.5x
Tier 5: 3.0x
```

### How to Increase Tiers
1. **Duplicate Collection**: Collect the same element again → Automatically upgrades tier by 1
2. **Manual Fusion**: Combine same element twice → Creates upgraded version
3. **Level-Up Selection**: Directly choose to upgrade existing element

### Tier Display
- Roman numerals shown next to element orb: I, II, III, IV, V
- Appears in charge UI slot display
- Updated dynamically as player collects duplicates

### Tier Storage
- Stored as Map with key: "element_slotIndex"
- Persists during game session
- Resets when collecting new element or discarding

### Tier Mechanics
- **Fusion Tier Loss**: When creating fusion, source elements reset to Tier 1
- **Tier Advantages**: Higher tier = exponentially higher damage output
- **Capped at Tier 5**: Maximum tier is 5 (3.0x damage multiplier)

## Part 5: Game Balance Analysis

### Damage Rankings (Base Damage)
```
HIGHEST DAMAGE:
1. Meteor: 4.0
2. Earth, Arcane, Holy, Wave, Thunder, Blast: 3.0-3.5
3. Fire, Lightning, Rock, Venom: 2.0-2.5
4. Ice, Crystal: 2.5
5. Water, Air, Poison: 1.0-1.5

LOWEST DAMAGE:
Poison: 1.0 (but has DoT compensation)
```

### Speed Rankings (Cooldown - Lower is Better)
```
FASTEST (1.5x fire rate):
- Air: 1200ms
- Music: 1500ms

VERY FAST:
- Lightning: 1500ms
- Chaos: 1400ms

SLOW:
- Earth, Void: 3000ms, 500ms respectively
- Mud, Lava: 3000ms, 600ms

SLOWEST:
- Death: 30000ms (intentional - instant kill mechanic)
- Time: 8000ms
- Gravity: 6000ms
```

### Special Mechanics by Element Type

**Piercing Elements** (Pass through multiple enemies):
- Poison, Venom, Crystal, Wave

**Homing Elements** (Track targets):
- Arcane, Meteor

**Bouncing Elements** (Chain to multiple enemies):
- Lightning (2 bounces)
- Thunder (3 bounces)
- Arcane (boomerang return)

**AOE Elements** (Area of effect):
- Air: 150px
- Mud: 150px
- Crystal (8 needles): Multidirectional
- Thunder: 100px
- Blast: 250px (largest active)
- Gravity: 400px (largest overall)

**Crowd Control Effects**:
- Freeze: Ice (2000ms)
- Stun: Rock (500ms)
- Slow: Water (0.5x), Ice (0.7x), Mud (0.2x - extreme)
- Burn: Fire, Meteor (duration varies)
- Shock: Lightning, Thunder (duration varies)
- Knockback: Earth, Air, Blast
- Poison: Poison (5000ms, 3 dmg), Venom (6000ms, 4 dmg)

### Element Archetype Classifications

**High Damage, Slow Casting** (Risk/Reward):
- Meteor (4.0 dmg, 1500ms), Earth (3.0 dmg, 3000ms)

**Balanced** (Good all-around):
- Fire, Arcane, Lightning (2.0-3.0 dmg, 1500-2400ms)

**Fast, Low Damage** (Speed-based):
- Air, Water, Poison (1.0-1.5 dmg, 1200-2000ms)

**Utility/Crowd Control** (Non-damage focused):
- Time (slowing), Gravity (pulling), Death (threshold kill)

**Projectile Count** (Multi-hit):
- Crystal (8 needles), Spiral (4 in pattern), Queen (multi-direction)

## Part 6: Recommended Balance Improvements

### Underperforming Elements
1. **Poison**: Very low damage (1.0) - consider +0.5 base damage
2. **Mud**: Extremely slow cooldown (3000ms) - reduce to 2500ms
3. **Void**: Cooldown too long (500ms) - increase to 2500ms?
4. **Water**: Low damage, low cooldown makes it weak - increase to 2.0 base damage

### Overpowering Elements
1. **Meteor**: Highest damage (4.0) + homing + AOE - may need balance
2. **Death**: Instant kill mechanic at 999 damage - working as intended (long cooldown balances)
3. **Gravity**: 400px AOE is massive + pulls - may need cooldown increase

### Fire Rate Suggestions
- Air: 1200ms is fastest - may be too strong for DPS
- Music: 1500ms for confuse element - good specialty role
- Void: 500ms is TOO SLOW - should be faster for utility

### Potential New Elements to Add
- Electric (standard), Frost (advanced), Ember (fire-based), Gale (wind-based)
