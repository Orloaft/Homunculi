## File Requirements Reminder

- **Format:** .wav (preferred), .ogg, or .mp3
- **Sample Rate:** 44100 Hz or 48000 Hz
- **Bit Depth:** 16-bit minimum
- **Channels:** Mono or Stereo (mono preferred for smaller file size)
- **Length:** Keep sounds short (see timing above)

Once you provide the files:

2. I'll add load.audio() calls for each
3. Wire them into appropriate spell functions
4. All will use the sound pooling system automatically
5. Pitch variation (0.9-1.1x) will add variety
