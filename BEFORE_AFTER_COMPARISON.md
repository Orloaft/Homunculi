**BEFORE**:
```

Chest 3:  Element (Earth)
Chest 4:  Element (Air)
Chest 5:  Element (Lightning)
Chest 6:  Chess! (Pawn) ← Finally!
Chest 7:  Element (Arcane)
Chest 8:  Element (Ice)
Chest 9:  Element (Steam)
Chest 10: Element (Lava)

```

**AFTER (with guarantee after 5)**:
```
Chest 1:  Element (Fire)
Chest 2:  Element (Water)
Chest 3:  Element (Earth)
Chest 4:  Element (Air)
Chest 5:  Element (Lightning)
Chest 6:  GUARANTEED Chess! (Knight) ← Pity timer!
```

**Player Impact**: ⬆️ 100% more chess pieces!

### **Change 2: Guaranteed Duplicates**

**BEFORE**:
```
Player has: Fire Tier 1
Level up rewards offered:
1. Water (random)
2. Earth (random)
3. Lightning (random)

Player picks Water → Now has Fire T1, Water T1
Next level up:
1. Air (random)
2. Arcane (random)
3. Ice (random)

Player never gets Fire duplicates → Stuck at Tier 1
```

**AFTER (40% duplicate chance)**:
```
Player has: Fire Tier 1
Level up rewards offered:
1. FIRE! (40% equipped duplicate)
2. Earth (fusion compatible: Fire+Earth=Lava)
3. Lightning (random)

Player picks Fire → Now has Fire T2!
Next level up:
1. FIRE! (40% equipped duplicate)
2. Water (fusion compatible: Fire+Water=Steam)
3. Air (random)

Player picks Fire → Now has Fire T3! 🎉
```

**Player Impact**: Tier 3-4 achievable in every run!

---

### **Change 3: Level Milestone Rewards**

**BEFORE**:
```
Level 5:  Choose 1 of [Fire, Water, Earth]
Level 10: Choose 1 of [Air, Lightning, Arcane]
Level 15: Choose 1 of [Ice, Steam, Lava]
Level 20: Choose 1 of [Crystal, Meteor, Thunder]

Player might get: 4 elements, 0 chess pieces, 0 guaranteed power spikes
```

**AFTER (with milestones)**:
```
Level 5:  Regular reward + GUARANTEED Common Chess (Pawn/Rook/Bishop)
Level 10: Regular reward + GUARANTEED Uncommon Chess (Knight/Queen/King)
Level 15: Regular reward + GUARANTEED (Fusion Element OR Tier+2)
Level 20: Regular reward + GUARANTEED Rare Chess (Saturn/Joker OR Tier+3)

Player gets: Elements + Chess + Power spikes = Excitement!
```

**Player Impact**: 100% guaranteed power progression!

---

### **Change 4: Dual Reward Tracks**

**BEFORE (competing rewards)**:
```
Level 1: Choose 1 of [Fire, Phoenix Heart, Extra Slot]
         → Pick Fire (no passive)
Level 2: Choose 1 of [Water, Magnitude, Move Speed]
         → Pick Water (no passive)
Level 3: Choose 1 of [Earth, Power Amp, Max Health]
         → Pick Earth (no passive)
Level 4: Choose 1 of [Air, Phoenix Heart, Extra Slot]
         → Pick Phoenix Heart finally! (no element this level)

Result after 4 levels: 3 elements, 1 passive (half rewards wasted)
```

**AFTER (dual tracks)**:
```
Level 1: ELEMENT track [Fire, Water, Earth] + PASSIVE track [Phoenix Heart, Magnitude, Extra Slot]
         → Pick Fire + Phoenix Heart (both!)
Level 2: ELEMENT track [Lightning, Air, Arcane] + PASSIVE track [Move Speed, Power Amp, Max Health]
         → Pick Lightning + Magnitude (both!)
Level 3: ELEMENT track [Ice, Steam, Lava] + PASSIVE track [Phoenix Heart 2, Extra Slot, Move Speed]
         → Pick Ice + Extra Slot (both!)
Level 4: ELEMENT track [Crystal, Meteor, Thunder] + PASSIVE track [Power Amp, Max Health, Magnitude 2]
         → Pick Crystal + Power Amp (both!)

Result after 4 levels: 4 elements, 4 passives (DOUBLE rewards!)
```

**Player Impact**: ⬆️ 200% more rewards per run!
