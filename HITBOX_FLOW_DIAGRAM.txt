SECTION 3: REGULAR ENEMY CREATION FLOW (27,620+)
================================================================================

    createEnemy(type, x, y)
         │
         ├─ Create sprite
         │   └─ const enemy = physics.add.sprite(x, y, texture, 0)
         │
         ├─ Set type identifier
         │   └─ enemy.enemyType = 'typename'
         │
         ├─ STEP 1: Apply Scale
         │   │
         │   └─ applySavedScale(enemy, 'typename')
         │       ├─ Check: typeof hitboxConfig !== 'undefined'?
         │       ├─ YES: scale = hitboxConfig.getScale('typename')
         │       │       enemy.setScale(scale)
         │       └─ NO:  enemy.setScale(1.0) [DEFAULT]
         │
         ├─ STEP 2: Apply Flip [INCONSISTENT - some types only]
         │   │
         │   └─ if (typeof hitboxConfig !== 'undefined' && hitboxConfig.loaded)
         │       └─ hitboxConfig.applyFlip(enemy, 'typename')
         │           ├─ if (config.flipX) sprite.setFlipX(true)
         │           └─ if (config.flipY) sprite.setFlipY(true)
         │
         │   ⚠️ NOTE: Only applied to some enemy types:
         │       ✓ Applied:    mushroom, bumblebee, bloboid, bombslime, 
         │                     arcaneslime, waterslime, lightningslime, 
         │                     earthslime, snowy, elkman, northerner, flyingdemon
         │       ✗ Missing:    tree, bat, soul, giantfly, slime, golem, fireslime
         │
         ├─ STEP 3: Apply Hitbox
         │   │
         │   └─ applyHitboxConfig(enemy, 'typename')
         │       ├─ Check: typeof hitboxConfig !== 'undefined' && hitboxConfig.loaded?
         │       ├─ YES: Call hitboxConfig.applyHitbox(enemy, 'typename')
         │       │       │
         │       │       ├─ Get config = this.hitboxes['typename']
         │       │       ├─ Validate: width, height, offsetX, offsetY present?
         │       │       ├─ YES: body.setSize(width, height)
         │       │       │       body.setOffset(offsetX, offsetY)
         │       │       │       ⭐ NOTE: NO DIVISION BY SCALE
         │       │       │       ⭐ Coordinates are UNSCALED
         │       │       └─ NO:  console.error(), return false
         │       │
         │       └─ NO or FAILED: Apply default hitbox
         │           └─ body.setSize(30, 30)
         │               body.setOffset(0, 0)
         │
         ├─ STEP 4: Create Shadow
         │   │
         │   └─ createShadowFor(enemy)
         │       ├─ Check: sprite.enemyType exists?
         │       ├─ YES: shadowConfig = hitboxConfig.getShadow(enemyType)
         │       │       shadowWidth = shadowConfig.width * sprite.scaleX
         │       │       shadowHeight = shadowConfig.height * sprite.scaleX
         │       │       ⭐ Shadow SCALES with sprite size
         │       │
         │       ├─ NO or missing: Use fallback hardcoded sizes
         │       │   └─ shadowWidth = shadowSizes[type].width * sprite.scaleX
         │       │
         │       └─ Create ellipse shadow at (x + offsetX, y + offsetY)
         │
         ├─ STEP 5: Play Animation
         │   └─ enemy.play('enemy-animation-key')
         │
         ├─ STEP 6: Set Speed
         │   └─ setEnemySpeed(enemy, baseSpeed)
         │
         └─ STEP 7: Add to Game
             └─ addEnemyToGroup(enemy)
                 ├─ enemies.add(enemy)
                 ├─ createShadowFor() [called again - different purpose]
                 └─ [if editor enabled] makeEnemyInteractiveForEditor()

    ⬇️

    ⬇️

    ⬇️

    ⬇️
Game Initialization (hitboxConfig.load())
    ⬇️
Enemy Creation Loop
    │
    ├─ Get scale from hitboxConfig.scales['typename']
    ├─ Apply scale via sprite.setScale()
    │
    ├─ Get flip from hitboxConfig.flips['typename']
    ├─ Apply flip via sprite.setFlipX/Y()
    │
    ├─ Get hitbox from hitboxConfig.hitboxes['typename']
    ├─ Apply hitbox via body.setSize/setOffset()
    │
    └─ Get shadow from hitboxConfig.shadows['typename']
       Apply shadow dimensions and position
